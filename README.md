# 星屿邮局 · Star Island Post

一款纯前端像素冒险小游戏。带着旅人穿过六座风格各异的小岛，收集星光、躲避障碍并把信送到灯塔。支持导入自己的像素动作图，创建最多两个自定义角色。

## 开始游玩

直接用浏览器打开 `星屿邮局-离线版.html`，无需安装或联网。也可以克隆本仓库，在项目目录中启动本地服务：

```bash
python -m http.server 8000
```

在浏览器访问 `http://localhost:8000`。源码入口是 `index.html`，无构建步骤和运行时依赖。推荐使用近期版本的 Chrome 或 Edge。

## 操作

| 操作 | 键盘 | 手机 |
| --- | --- | --- |
| 移动 | ← / → 或 A / D | 左右方向键 |
| 跳跃、二段跳 | 空格、W 或 ↑ | 跳跃按钮，空中再按一次 |
| 攻击 | J，可长按 | ⚔ 按钮 |
| 投递 | E | 信封按钮 |
| 暂停 | P 或 Esc | 暂停按钮 |

每关收集全部星光后，前往右侧灯塔投递。六关共有 50 颗星光，第六关结束后会显示胜利结算。怪兽、雨云和落水会造成伤害，中途邮站可以恢复一次生命。

## 自定义角色

打开角色工坊，上传**已经制作好的像素动作图**；游戏不会根据照片自动生成角色。可使用 PNG、JPG 或 WebP，单张不超过 16 MB。建议使用透明或纯亮绿背景、等宽帧和完整全身人物。

支持两种布局：

1. **原项目布局**：待机图为 1 行 4 列；动作表为 3 行 4 列，依次为行走、跳跃、攻击。
2. **独立动作**：待机、行走、跳跃各一张 1 行 4 列的图，可额外上传一张 4 帧攻击图。

工坊可预览动作和朝向、调整名字并保存。角色卡上的「编辑」可以单独更换动作，未更换的动作会保留。没有专属攻击图时，游戏会根据行走帧播放自动挥击动作。

角色数据、已选角色、解锁进度和最快纪录存储在**当前浏览器本地**，不会自动同步到其他设备或浏览器。清除浏览器数据可能移除存档。工坊可导出角色 JSON 包；当前界面支持导出，但不提供 JSON 包重新导入功能。

## 项目结构

```text
index.html          页面和游戏入口
style.css           页面样式
workshop.css        角色工坊样式
victory.css         胜利结算样式
game.js             游戏循环、输入、存档和渲染
levels.js           六关地图和玩法配置
combat.js           怪兽及战斗逻辑
sprite-workshop.js  动作图导入、预览与角色编辑
assets-data.js      内置角色图像数据
xiaozi-punch.js     小紫打拳素材及旧角色更新数据
assets/             像素素材
星屿邮局-离线版.html  独立离线版本
```
